# mocap-sync-fw

**Status: parked.** ESP32 firmware for an LED flash sync marker. The hardware isn't
available and the baseline syncs cameras on the recorder's host clock instead, so
nothing here is scheduled. The planned work is kept in `initiatives/baseline/` so it
can be picked up if a measured improvement ever justifies the hardware — see
`mocap-capture/initiatives/future/README.md`.
